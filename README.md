## 📖 Overview

A developer portfolio crafted with **React 19**, **Next.js**, **Supabase**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**. Designed from the ground up for high performance, tactile micro-interactions, responsive cross-device layouts, and clean full-stack architecture.

Showcases real-world applications, technical capabilities, structured workflow methodologies, and direct contact channels.

---

## ✨ Key Features

- ⚡ **Lightning Fast Performance**: Built on Vite with instantaneous HMR and optimized production bundles.
- 🎨 **Modern Dark Aesthetics**: Curated color harmony, glassmorphic elements, ambient radial glows, and typography pairing (Inter & Poppins).
- 🎬 **Fluid Micro-Animations**: Smooth entry reveals, tab transitions, hover physics, and reactive indicators powered by Framer Motion.
- 📱 **Fully Responsive Layout**: Mobile-first architecture with desktop/mobile device preview toggles for showcase projects.
- 🔍 **SEO & Social Optimization**: Structured Open Graph metadata, semantic HTML5 hierarchy, canonical URLs, and Lighthouse-optimized Core Web Vitals.
- 🧩 **Modular Component Architecture**: Clean separation of sections, reusable UI cards, and structured project data schemas.

## 📁 Project Structure

```bash
frontend/
├── public/                # Static assets, SVG icons, and favicons
├── src/
│   ├── assets/            # Project showcase imagery and screenshots
│   ├── components/        # Reusable UI primitives (Navbar, Card, etc.)
│   ├── sections/          # Page sections
│   │   ├── Hero.jsx       # Introduction, badge, and primary CTAs
│   │   ├── About.jsx      # Background, bio, and philosophy
│   │   ├── Skills.jsx     # Core technical proficiencies
│   │   ├── TechStack.jsx  # Tools, libraries, and frameworks
│   │   ├── Projects.jsx   # Featured work with live previews & tabs
│   │   ├── Services.jsx   # Development & SEO service offerings
│   │   ├── Process.jsx    # 4-step engineering and delivery workflow
│   │   ├── Timeline.jsx   # Milestones and journey history
│   │   ├── Contact.jsx    # Interactive contact form & direct channels
│   │   └── Footer.jsx     # Social links, sitemap, and copyright
│   ├── App.jsx            # Root application layout
│   ├── index.css          # Tailwind CSS configuration & design tokens
│   └── main.jsx           # Application entry point
├── index.html             # Document shell with SEO meta & Google Fonts
├── vite.config.js         # Vite configuration
└── package.json           # Scripts and dependencies
```
